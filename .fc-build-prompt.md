## 2. Cómo funciona el helper Firecrawl (VERIFICADO, no lo redescubras desde cero)

- Invoca SOLO vía subprocess: `python3 ~/workspace/custom-connectors/custom.firecrawl/bin/client.py call-tool --name <TOOL> --arguments-file <tmp.json>`.
- Herramientas permitidas: `firecrawl_search`, `firecrawl_scrape`, `firecrawl_map`, `firecrawl_credit_usage`. NUNCA otra.
- NUNCA extraigas, pegues, imprimas ni guardes la API key cruda de Firecrawl en ningún lado: ni variables de entorno, ni archivos, ni logs, ni chat, ni código. El helper gestiona la credencial; tú solo le pasas el nombre de la herramienta y el JSON de argumentos (archivos temporales con `tempfile`, borrados tras cada llamada).
- Salida del helper: JSON por stdout con `content[0].text` (string JSON) y a veces `structuredContent`. Parseo: `json.loads(stdout)` → `result["structuredContent"]` si existe, si no `json.loads(result["content"][0]["text"])`. Si `result.get("isError")` es true o el proceso sale con código != 0, trátalo como fallo de esa llamada (log + seguir).
- `firecrawl_credit_usage` con argumentos `{}` devuelve `{"remainingCredits": N, "planCredits": M, "billingPeriodStart": ..., "billingPeriodEnd": ...}`. VERIFICADO 2026-11-15: quedan **1500 créditos**, periodo hasta **2026-12-02**. (Ojo: un `firecrawl_search` de prueba NO movió el contador de 1500; el coste real por llamada puede no reflejarse al instante. Mide el delta antes/después y repórtalo tal cual, sin inventar costes por llamada.)
- `firecrawl_search` con argumentos `{"query": ..., "objective": ...}` (ambos obligatorios) devuelve `{"success": true, "data": {"web": [{"url": ..., "title": ..., "description": ...}, ...]}}`. VERIFICADO: una búsqueda de empleos remotos devolvió 10 resultados mezclando páginas de listado/categoría (p. ej. `wellfound.com/role/r/automation-engineer`, `wellfound.com/remote`) y vacantes individuales (p. ej. `wellfound.com/jobs/4644223-ai-automation-specialist-web-development-company`, `wellfound.com/jobs/3714182-ai-agent-implementation-specialist`, con descripción en markdown que incluye título, empresa, modalidad y a veces sueldo). Tu parser debe distinguir vacante individual de página de categoría.
- `firecrawl_scrape` con `{"url": ..., "objective": ...}` devuelve el contenido markdown de la página. `firecrawl_map` con `{"url": ...}` lista URLs de un sitio.
- Timeout por llamada al helper: 120 s. Sin reintentos en bucle: como mucho 1 reintento por llamada fallida (salvo 429 / créditos agotados, que NO se reintentan).

Registra en el log los créditos consumidos (delta antes/después; si el delta es 0, dilo tal cual).
